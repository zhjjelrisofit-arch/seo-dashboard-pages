# SEO Dashboard (Public Mirror)

JelriSoFit & VyblooJug 自然搜索表现看板，由 GitHub Pages 托管。

本仓库为静态前端镜像，数据由私有仓库 `seo-dashboard-private` 的 GitHub Actions 工作流每日同步。

## 内容

- `index.html` — 看板入口
- `css/` — 样式
- `js/` — 前端逻辑
- `data/` — 前端 JSON（品牌词 + 品类词聚合结果）

## 访问

GitHub Pages URL：`https://zhjjelrisofit-arch.github.io/seo-dashboard-pages/`

## 数据来源

- 品牌词：GSC 官方 Branded 导出
- 品类词：GSC API + 755 词固定词库匹配

源代码与历史原始数据保留在私有仓库，不在本仓库公开。
